# PILLYI G SHANKAR Portfolio

Premium modern frontend-only personal portfolio website for **PILLYI G SHANKAR** (Frontend & Full-Stack Developer, Andhra Pradesh, India).

## Highlights

- Next.js + TypeScript + Tailwind CSS architecture
- Framer Motion-based smooth animations and scroll reveal effects
- Sticky responsive navbar with mobile menu
- Minimal luxury beige theme with premium card hierarchy
- Bento-style projects grid, journey timeline, achievements, and contact section
- Reusable UI and section components inspired by shadcn patterns

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn-style reusable UI components

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```
